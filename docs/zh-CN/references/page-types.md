# 四类页面，四种做法

先判断你要做的是哪一类页面，再动手。同一个网站里不同页面可以用不同做法，但**设计变量（字体、焦点蓝、标志）要保持一致**。

| 类型 | 典型页面 | 气质 | 关键词 |
|---|---|---|---|
| A. 品牌 / 展示页 | 首页、商店、产品介绍、活动页 | 惊艳、克制 | 黑白灰交替、大标题、商品是主角 |
| B. 正式页 | 公告、条款、隐私政策、调研、帮助文档、API 文档 | 可信 | 纯色底、文档排版、细线表格 |
| C. 工具页 | 邮箱、后台、控制台、数据列表 | 高效 | 白底、信息密度、搜索和筛选 |
| D. 流程页 | 登录、注册、结账、兑换、表单 | 专注、安心 | 一件事、少字、状态清楚 |

**两种语气**：A 类和结账、兑换用**商务语气**（白 / 浅灰 / 黑、系统黑体、蓝色胶囊）；登录注册、关于我们、分享卡片、品牌宣言这类「身份时刻」用**编辑语气**（暖纸白或暖黑、衬线大字、墨色按钮、细边框）。一个页面只用一种语气；两种语气共用间距、动效和焦点规则。

---

## A. 品牌 / 展示页

这是本 skill 的主体，具体写法见 `SKILL.md` 的「骨架」「主角」两节，组件写法见 `components.md`。

**页面节奏**（参考结构，按需增删）：

```
导航（48px，毛玻璃，sticky）
首屏 hero（黑底，或者白底配强主视觉；高度约 600px，手机上更矮）
区块 1（浅灰 #f5f5f7）
区块 2（白 #fff）
通栏横幅（黑底 + 一点品牌色柔光）
区块 3（浅灰）
……
页脚（浅灰，12px 小字）
```

- 每个区块：眉标（可选，12–14px 强调色）→ 大标题（一句话说价值）→ 一句副标题 → 内容（卡片网格或横向滚动货架）→ 文字链接「了解更多 ›」。
- 卡片网格：桌面 4 列或 3 列，平板 2 列，手机 1 列或横向滚动。卡片之间 18–22px 间距。
- 商品卡片：图片在上（大圆角，留白多），名称、一句卖点、价格、按钮。价格数字用 `tabular-nums`。
- 不可用的商品不显示。

## B. 正式页（文档式）

**原则**：可信 > 好看。不用动态背景、玻璃效果、光晕、渐变大数字。

**设计变量**（浅 / 深两套，默认跟随系统，用户切换后记在 localStorage）：

```css
:root{
  --bg:#fff; --surface:#f8f9fa; --ink:#202326; --text:#51565c; --muted:#6c7278;
  --line:#e9ebed; --line-strong:#dadddf;
  --accent:#476951; --accent-soft:#edf4ee;        /* 沉稳的墨绿，只用于眉标、链接、当前项 */
  --code-bg:#f6f7f8;
  --sans:Inter,-apple-system,BlinkMacSystemFont,"Segoe UI","PingFang SC","Microsoft YaHei",sans-serif;
  --mono:"SFMono-Regular",Consolas,"Liberation Mono",monospace;
  --ease:cubic-bezier(.23,1,.32,1);
}
:root[data-theme=dark]{
  --bg:#151618; --surface:#1d1f21; --ink:#ededee; --text:#b4b8bc; --muted:#8d9399;
  --line:#2b2e31; --line-strong:#3b4044; --accent:#a4c3aa; --accent-soft:#25322a; --code-bg:#1c1e21;
}
```

**排版**：

| 元素 | 规格 |
|---|---|
| 正文 | 14px / 1.75，颜色 `--text` |
| 导语 lead | 15px / 1.9，最大宽度 680px |
| 眉标 | 12px，字重 550，`--accent` |
| h1 | 34px / 1.3，字重 650，字距 -1px，`text-wrap: balance`（手机 30px） |
| h2 | 22px / 1.45，字重 620，字距 -.4px，上边距 44px |
| h3 | 18px / 1.5，字重 620 |
| 元信息行 | 10px 等宽字，字距 .05em，竖线分隔（日期、版本、阅读时长） |
| 表格 | 12px / 1.8，外框 1px `--line-strong`、圆角 8px，表头 `--surface` 底，单元格内边距 12px 15px |
| 行内代码 | .86em 等宽字，1px 细框，圆角 4px |
| 提示框 callout | `--accent-soft` 底，左侧一个圆圈 i 图标，12px / 1.9 |

**布局**：桌面三栏（左目录 256px / 正文最大 876px / 右侧本页大纲 216px）；小于 1200px 时隐藏右侧大纲；小于 680px 时左侧目录变成抽屉。顶栏 72px，白底，1px 底线，不做毛玻璃。

**交互**：标题悬停时显示 # 锚点；`⌘K` 搜索弹窗；代码块右上角放复制按钮，复制成功只弹一个小 toast（深色底、底部居中）。

## C. 工具页（Gmail / Google 账号页式）

**原则**：工具的好坏取决于布局和交互，不是配色。改版要改的是「找东西快不快」。

- 白底浅色，不做深色分支（除非产品本来就要求深色）。
- 左侧导航 + 顶部搜索框（圆角大、浅灰底，聚焦后变白并加阴影）+ 列表主体。
- 列表行高 40–48px，悬停时浅灰底，选中时淡蓝底；行内操作按钮悬停才出现。
- 信息密度高于品牌页：正文 13–14px，标签用小号胶囊。
- 筛选和分类常驻可见，不藏在二级菜单里。
- 空状态：一句话加一个主要操作，不放大插画。

## D. 流程页

**共同原则**：一屏只做一件事；主按钮只有一个；错误信息在提交后才出现，并且就近显示在出错的字段下方。

### 登录 / 注册（用编辑语气）
登录是用户和品牌的「身份时刻」，用编辑语气（见 `tokens.css` 的 `.editorial`），不用商店的蓝色胶囊骨架。
- 双栏，左宽右窄（约 `1fr : .92fr`）：左边是一句衬线大字（品牌对用户说的话，`clamp(40px,4.2vw,62px)`，字重 500，`text-wrap: balance`）+ 一句副标题 + 表单卡（最宽 456px，1px 细边框，圆角 24px，不加重阴影）；右边是产品自己的画面（自制短视频或真实界面，圆角 28px），只在 1024px 以上加载，手机上整块不显示、不下载。
- 主按钮用墨色（深色主题是白底黑字，浅色主题是黑底白字），圆角 10px、高 44px，不用蓝色。
- 默认跟随系统的深浅色：深色是暖黑 `#141413`，浅色是暖纸白 `#faf9f5`；`<head>` 里内联底色，防止首帧白闪。
- 衬线字只取页面用到的字形做子集（中文子集十几 KB），改文案要重新做子集。
- 表单按步骤推进：邮箱 → 密码（或验证码），一步只问一件事；步骤切换横向滑动（前进从右边进，后退从左边进）。
- 人机验证：一进入这一步就在后台静默运行，验证框先藏起来；主要输入填完后才自然露出；只有提交时确实没完成，才显示提示。
- 条款默认同意，用一行小字说明，不要强制勾选框（法律另有要求的除外）。

### 结账 / 支付
- 保持弹窗形态，不要跳到一个「品牌支付页」。
- 一眼能看到三样东西：金额、付款方式（二维码或按钮）、剩余时间（倒计时用 `tabular-nums`）。
- 订单摘要放在侧边卡片里，可以折叠。
- 付款成功的反馈要即时、明确，然后自动进入下一步。

### 兑换 / 激活 / 长任务
- 左侧产品列表，右侧操作面板（手机上把产品列表变成顶部的横向页签）。
- 输入框够大，支持粘贴后自动识别和校验格式；帮助文案只写一句「打开哪里、复制什么」。
- 提交后按钮原地长成进度卡（见 `motion-perf.md`「长任务的进度表现」）。
- 结果只显示结果本身，不附加「下一步建议」。
